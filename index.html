This is the development entry point

It needs the dev server to run. To use PaiseWise:

  • Test it on your PC and phone: double-click local-testing\start-local-server.bat.
  • Just use it: run npm run build, then double-click dist/index.html — that build runs straight from disk.
  • Develop it: run npm install then npm run dev and open the URL it prints.
